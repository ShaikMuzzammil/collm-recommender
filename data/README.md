# Data Directory

CoLLM is evaluated on two public datasets. This directory holds raw and processed data.

## 📦 Datasets

### ML-1M — MovieLens 1M
| Field | Value |
|-------|-------|
| Source | [GroupLens](https://grouplens.org/datasets/movielens/1m/) |
| Users | 839 (after temporal split) |
| Items | 3,256 |
| Interactions | ~51,000 |
| Positive threshold | Rating > 3 |

```bash
# Download
wget https://files.grouplens.org/datasets/movielens/ml-1m.zip
unzip ml-1m.zip -d ml-1m/
```

### Amazon-Book
| Field | Value |
|-------|-------|
| Source | [McAuley Lab](https://cseweb.ucsd.edu/~jmcauley/datasets.html#amazon_reviews) |
| Users | 22,967 (≥ 20 interactions) |
| Items | 34,154 (≥ 20 interactions) |
| Interactions | ~779,000 (year 2017) |
| Positive threshold | Rating ≥ 4 |

```bash
# Download (Books category)
wget https://jmcauley.ucsd.edu/data/amazon_v2/categoryFiles/Books.json.gz
```

## ⚙️ Preprocessing

```bash
cd scripts/
bash download_data.sh       # Download datasets
python preprocess.py        # Process into train/val/test splits
```

## 📊 Temporal Split Strategy

Both datasets are split **by timestamp** to prevent data leakage:

- **ML-1M**: Most recent 20 months → 10 train / 5 val / 5 test
- **Amazon-Book**: Year 2017 → 11 months train / 0.5 months val / 0.5 months test

This mirrors real-world deployment where historical data trains the model and future data evaluates it.
